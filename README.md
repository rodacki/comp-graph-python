# Computação Gráfica em Python — exemplos (edição 2024, referência)

Exemplos da disciplina **CCB0941 — Computação Gráfica** (IFC Blumenau) usados na
**oferta de 2024**. Vão de "hello OpenGL" a um editor 2D completo em PyQt6 +
ModernGL, empacotados com Poetry (`poetry run ex01-hello`, etc.). Usam PyOpenGL
(GLUT/moderngl).

**Mantido como referência.** O código da **edição atual (2026.2)** — voltado aos
alunos, com stack e pedagogia novas — fica em outro repositório:

> **https://github.com/rodacki/cg-ifc-2026-2**

Os exemplos aqui em `src/cg_examples/` seguem úteis como base a garimpar (models,
State pattern do editor 2D, matemática do ColorPicker), reescritos quando migram
para a edição nova.
